# v0.1.2: Releases and versions

**New:** Laundry Hub now publishes a GitHub release for every version, so HACS can offer updates.
- The version HACS shows and the version Home Assistant shows always match.

**Change:** the tap station firmware now reports the same version as the integration (0.1.2). Firmware is not released separately; reflash the stations from the ESPHome Device Builder after updating.

No change to how Laundry Hub works. Not yet tested on real hardware.
