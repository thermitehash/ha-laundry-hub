# v0.2.3: Ready for the iPhone app

**New:** Laundry Hub can now serve a second app (the upcoming iPhone app) alongside the Laundry panel. Nothing changes in the panel, the stations, the actions or the entities.

**New:** App access, in Laundry Hub → Configure. "Admins only" (the default) keeps everything as it is. "Household" lets other Home Assistant users, such as the kids, use the app: each person sees, taps and edits only their own garments. You choose which person each Home Assistant user is; people already linked to a user in Settings → People are filled in for you.

**New:** a phone can act as a tap station. Tapping a tag on the phone works like tapping it on a station: unknown tags appear in Add, and moving a garment to a closet, the wash or drying goes through the same rules. The zone light flashes and automations see phone taps too (the station shows as "Phone · <device>").

**New:** offline sync for the app. Every change gets a revision number, so the app can catch up after being offline and won't overwrite a change someone else made in the meantime.

**Fix:** garment photos are now only served to people allowed to see that garment. Before, any logged-in Home Assistant user with a photo's address could open it.

**Change:** stored data gains revision numbers. v0.2.2 can still read it, so going back needs no restore.

The tap station firmware didn't change, so there's no need to reflash the stations.

Not yet tested on real hardware.
