# v0.2.4: Kids can add their own clothes

**Fix:** one order email that can't be read no longer stops the purchase import. Each email gets three tries; after that it's set aside as "couldn't be read" and every other email keeps importing. Settings and Configure show "1 email couldn't be read" with the store and date, and **Retry unreadable emails** reads them again. Shipping notices that list no items are skipped quietly.

**Fix:** reading order emails is more forgiving: prices like "$12.99", missing quantities and empty fields no longer cause a failure, and a failed read is tried once more in a simpler way before it counts. The log now says what went wrong.

**New:** with App access set to Household, family members can add their own garments from the app. Tap the new tag with your phone, then give it a name, a wash bin and a dry type. It's always added as yours, and only the tag you just tapped can be added (within 30 minutes).

**New:** when a family member adds the first photo to one of their own garments, it's described automatically, just as in the Laundry panel. Re-describing and editing the description stay with the admins.

**Change:** family members can no longer edit description details by hand; admins still can.

**Fix:** with Wardrobe off, opening Laundry Hub's Configure dialog no longer fills the Home Assistant log with "Failed to format translation … status" warnings.

The tap station firmware didn't change, so there's no need to reflash the stations.

Not yet tested on real hardware.
