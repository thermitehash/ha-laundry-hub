# v0.2.2: Purchase inbox polish

**New:** your own stores in the store list: Lands' End, American Tall, L.L.Bean, Duluth Trading, Eddie Bauer, Outdoor Research, Backcountry, Columbia, Carhartt, Coldwater Creek, Brooks Brothers, Orvis, Darn Tough, Woolx, Outway, MeUndies, Underoutfit, Truekind, Cinderella Shoes, Blauer and First Tactical. Shipping emails these stores send through Narvar are recognised too.

**New:** Shopify stores by name. Shops on Shopify all send from the same address, so add a shop by its name (First Tactical is built in). Only emails with that name in the sender's name or the subject are read; mail from every other Shopify shop is ignored.

**New:** uniform suppliers. Garments matched to a Blauer or First Tactical order start with "Uniform" ticked (untick it if it isn't). In Purchases, Laundry Hub offers once per store to mark garments you already matched from them as uniform.

**New:** an "Archived" view in Purchases shows dismissed and auto-archived cards, newest first. Restore puts a card back in the list; its photo is downloaded again when the email had one.

**New:** Settings shows a Purchase emails row: connected or not, the number of stores, the last check, new cards and the last problem.

**Change:** a shipping email that lists a clothing item not yet on any card of that order now adds a card for it. Non-clothing items are never added this way.

**Change:** a restored card is archived again only after the full waiting period, counted from the restore.

The tap station firmware didn't change, so there's no need to reflash the stations.

Not yet tested on real hardware.
