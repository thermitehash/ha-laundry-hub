# v0.2.8: Garments without a tag

**New:** a garment no longer needs an NFC tag. In Add, choose "No tag (wardrobe only)" next to tapping a tag, or use "New garment from this" on a purchase card. Untagged garments get the same photos, details, AI description and fit as any other, with a small "No tag" badge and a "Tagged / No tag" filter in Closet.

**New:** an untagged garment's laundry state is set by hand, with "To laundry" and "Clean / put away" on the garment. Laundry Hub never guesses where an untagged garment is, never calls it missing, and leaves it out of the closet and laundry-bin counts. A state set by hand a long time ago is treated as less certain.

**New:** "Attach tag" on a garment links the next new tag tapped at any station or with the app, within 2 minutes; or type the tag's ID. If the tag is already on another garment, "Move tag here" moves it. "Replace tag" (for a lost tag) and "Remove tag" (back to no tag, keeping its history) are on every tagged garment.

**New:** when a new tag is tapped, its notification and the Add page also offer "Link to an untagged garment…", with the most likely garments first.

**New:** with App access set to Household, family members can add untagged garments for themselves, set their laundry state, and attach, replace or remove tags on their own garments.

**Change:** "Not clothing" on a purchase card now keeps its photo, so Restore brings it back without downloading it again. Archived and dismissed cards, and their photos, are removed a year after they were archived or dismissed.

The tap station firmware didn't change, so there's no need to reflash the stations.

Not yet tested on real hardware.
